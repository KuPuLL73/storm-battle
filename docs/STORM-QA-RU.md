# Проверка «Шторм батл»

19 октября 2026 года. Windows, TypeScript strict, Node.js 20.12.1, Chromium через Playwright. Проверена новая игра; старый движок поезда остаётся в общей модульной проверке.

## Результаты

- `npm test`: 71 тест прошёл, в том числе 42 теста движка, прогрессии и экономики «Шторм батл» и 29 общих/исторических тестов.
- `npm run build`: проверка типов и production-сборка прошли.
- `$env:GAME_URL='http://127.0.0.1:4173'; npm run test:browser`: 16 сценариев прошли на production-сборке.
- `$env:GAME_URL='http://127.0.0.1:4173'; npm run test:progression`: четыре комплексных сценария прошли на production-сборке.
- `$env:GAME_URL='http://127.0.0.1:4173'; npm run test:economy`: три комплексных сценария — новый баланс аимки на старом сохранении, иконки на трёх ширинах, локальные и SDK-подарки.
- `node scripts/storm-visual-check.mjs`: финальная проверка аватаров, обеих веток обработки ориентации и мобильных экранов прошла.

Отчёты: `artifacts/storm/browser-report.json`, `artifacts/storm/progression-browser-report.json`, `artifacts/storm/visual-report.json`, `artifacts/storm/economy-browser-report.json`. Скриншоты: `artifacts/storm/`.

## Что проверено

- Каталог 33 кейсов/73 скина, десять уровней, минимум три кейса на уровень, четыре стартовых предмета, просмотр закрытого кейса и отдельные проценты дропа. Панель RTP убрана, обычные кейсы имеют 35% прибыльных исходов и 88% среднего возврата. Два случая 50/50 сохраняют точные равные шансы с пересчитанными ценами. Баланс рассчитан для всех 33 кейсов, включая изменённые цены тематических пулов.
- ×2 доступно с уровня 3, ×3 с уровня 5, ×5 с уровня 8. Проверены ограничения движка без списания при отказе, кнопки интерфейса и фактическое число лент.
- Премиальные сундуки за уровни 2–10 выдаются один раз, содержат дорогой предмет и сохраняют результат до показа. Проверены реальное повышение уровня, миграция старых сохранений, перезагрузка результата, повторная попытка получения, ограничения вместимости и отказ без частичного изменения состояния.
- Результат и списание сохраняются до анимации. Перезагрузка открытия/апгрейда/контракта/батла восстанавливает результат, не проводя операцию повторно.
- Открытия ×3/×5: по ленте на предмет, совместная пауза, центр результата после изменения ориентации, уведомление нового уровня, быстрый повтор и продажа.
- Аимка: заработок за реальные попадания; отсутствие дохода при удержании/ожидании; три ветки прокачки; серии, промах, таймаут, бустер и сохранение рекорда/дохода. Старые уровни фармилки переходят в награду за попадание.
- Цель накопления на кейс и возврат к выбранному количеству после заработка в аимке.
- Контракты расходуют выбранные предметы один раз и выдают результат из заявленного пула.
- Лобби: выбор кейса/числа раундов, стоимость, две прокрутки, итоговая выдача, аватары, пояснение симуляции, сохранение ника соперника.
- Задания завершаются реальными попаданиями, требуют кнопки получения и не платят повторно.
- Локальные рекламные кнопки отключены, в том числе после обновления таймера. Контролируемый SDK не выдаёт бонус при закрытии без onRewarded; повторные callbacks дают одну награду. Рекламный кейс не списывает поинты, фиксирует один дроп и сохраняет задержку после перезагрузки.
- Продажа с рекламным бонусом +50% не имеет прежнего потолка; повторный receipt не даёт вторую выплату.
- Временные метки настоящего масштаба 2026 года не обрезаются при загрузке: freeAt/dailyAt/wheelAt/boostUntil/giftAt. Ранняя выдача наград после перезагрузки предотвращена.
- Все семь разделов проверены при 1440×1000, 390×844, 844×390 и 320×568: картинки загружаются, горизонтального выхода страницы нет. На телефоне доступны все семь кнопок навигации, аимка, диалоги выбора апгрейда и настройки. В горизонтальной ориентации проверены адаптация аимки и работа попаданий.
- Настройки сохраняют язык и ориентацию; недоступность API закрепления показывает подсказку и не ломает интерфейс. Поддерживаемая ветка проверена с управляемыми mock-функциями полного экрана и lock; физический поворот устройства этим не подтверждается.
- Авторские файлы графики доступны в production-сборке: 12 контейнеров, баннер оружейной мастерской, премиальный сундук, эмблема, аватар и иллюстрации бонусов. Проверены обе картинки участников лобби. Визуально проверены каталог, мобильная навигация и диалог премиальной награды; исправлено растягивание монеты стилем картинки результата.

## Проверка перебалансировки

- Возврат каждого кейса ниже 90%; редкий дорогой выигрыш остаётся возможным. Контракты сохраняют собственный профиль 96%.
- При любых десяти уровнях коллекционера и всех двадцати уровнях награды аимка платит не более 61 монеты за попадание без рекламы и 122 с ×2. Цена открытого кейса на доход не влияет.
- Проверены дорогие улучшения, минимальный срок окупаемости прибавки без серии, запрет покупки выше доступного уровня, в том числе через старый farmUpgrade. Промах не позволяет обойти 350 мс между попаданиями.
- Сохранение по скриншоту пользователя: 780 XP, 94 599 монет, награда 14, мишень 10, серия 5 — после загрузки те же значения, базовый доход 30 вместо 2292.
- Опыт открытия/апгрейда/контракта/батла/колеса и десять порогов уровней отдельно зафиксированы проверкой; изменения XP отменены по просьбе пользователя.
- Подарки: без receipt и без рекламы не выдаются; успешный SDK callback выдаёт один предмет, расходует один receipt и перезапускает только свой таймер. Ошибка/закрытие, повторные callbacks, повторный receipt, полная сумка и перезагрузка проверены.
- Семь разных иконок вкладок и шестерёнка настроек загружаются как прозрачные WebP. Панель помещается при ширине 320 и 390 px, настройки открываются.

## Что ещё не проверено

Настоящие объявления, облачное сохранение и SDK-пауза в черновике Яндекса; реальные Android/iOS и системные ограничения ориентации; привлекательность темпа игры для пользователей. Моки, эмуляция и модель идеальной аимки не подтверждают эти результаты.

Локальный архив `artifacts/storm-battle-preview.zip` не означает публикацию, одобрение модерации, подтверждение прав на CS-графику или возрастной маркировки. Материалы старой игры про поезд к текущему выпуску не относятся.
