# Подготовка «Шторм батл» к отправке

Обновлено 20 октября 2026 года. Текущая игра — «Шторм батл», исходники `src/storm/`. Старый поезд и его материалы не использовать: историческая инструкция сохранена в `TRAIN-RELEASE-RU.md`.

## Файлы

- Архив игры: `artifacts/storm-battle-yandex.zip`. В корне один `index.html`; внутри только production-код и ресурсы игры. Исходники, тесты, документы и материалы поезда исключены.
- Промокомплект: `artifacts/yandex/`. Иконка 512×512, две обложки 800×470, по три десктопных и два мобильных скриншота на язык; видео RU/EN, 1280×720, до 22 секунд, H.264 MP4 без аудио.
- Тексты: `STORE-LISTING.md` и `store-listing.json`, копия JSON в промокомплекте. Длины полей проверены.
- Состав архива, размеры и SHA-256 каждого файла: `artifacts/yandex/build-manifest.json`. Метаданные изображений/видео: `media-manifest.json` и `promo-manifest.json`.

Архив игры загружается в поле «Архив». Картинки и видео загружаются отдельно в соответствующие поля карточки; не загружать ZIP с промоматериалами вместо игры.

## Повторяемая сборка

```powershell
npm test
npm run release
npm run preview
```

При работающем production-просмотре:

```powershell
$env:GAME_URL='http://127.0.0.1:4173'
npm run test:browser
npm run test:progression
npm run test:economy
npm run test:submission
node scripts/storm-visual-check.mjs
npm run promos
npm run capture
```

Для Chromium: `npx playwright install chromium`. Для MP4 необходим `ffmpeg` в PATH либо `FFMPEG_PATH`. Не пересобирать `dist` во время записи материалов или проверки production-сборки. На Windows перед новой сборкой остановить именно preview этого проекта, если файлы заблокированы.

`release` проверяет TypeScript, создаёт ZIP, проверяет имена, лимит 100 МиБ, корневой HTML и распаковку каждого файла по SHA-256. Старый архив заменяется только после успешной проверки нового. Никакой отправки на модерацию команда не делает.

## Черновик

[Черновик №634880](https://games.yandex.ru/console/application/634880#application-info-draft).

Название RU: «Шторм батл - соревнование за лучший дроп». EN: «Storm Battle - Race for the best drop». В форме Консоли длинное тире было удалено при вводе, поэтому используется обычный дефис; слова согласованы с обложками и игрой.

Платформы: десктоп, Android, iOS. Ориентация любая. Языки RU/EN. Категории «Казуальные» и «Симуляторы», десять тегов и 86 символов ключевых слов (см. `store-listing.json`). Облачные сохранения включены, поскольку игра вызывает Player.getData/setData. Включена отсроченная публикация: «Проверка SDK и финальная подготовка выпуска».

Возраст: в черновике заявлено 6+ для коллекционного симулятора без насилия над персонажами, денежных ставок и реальных призов. Предварительные 18+ отменены: общего правила «все кейс-симуляторы — 18+» не найдено. Случайные исходы и потеря предметов честно описаны. Сходные опубликованные Upgrade и «Баттл Дроп» имеют 6+, однако это не подтверждает маркировку нашей игры. Требуется решение модерации.

20 октября Консоль показывает уведомление о временных ограничениях регистрации, загрузки видео, отправки и обработки заявок. Проверять доступность функций по фактическому результату; предупреждение не доказывает, что все эти функции всегда недоступны.

20 октября архив обработан со статусом «Готово». Сохранены RU/EN тексты, иконки, обложки, по три десктопных и два портретных скриншота на язык. Оба видео загружены; оба появились в проигрывателях после обработки. Отправка на модерацию не выполнялась.

В настоящем черновике debug-панель подтвердила SDK v2, Game Ready через 2862 мс, I18N и GameplayAPI. При rewarded наблюдались рекламное окно, пауза/остановка Gameplay и последующее возобновление. Это не полная проверка всех исходов рекламы и облачного восстановления.

## Проверка в Яндексе

1. После обработки архива открыть черновик через кнопку тестирования с debug-панелью.
2. Убедиться, что SDK и Game Ready зарегистрированы после появления интерфейса. Путь SDK — `/sdk.js`, без копии SDK в архиве.
3. На чистых настройках проверить язык SDK RU/EN. Вручную выбранный язык должен сохраняться после перезагрузки.
4. Проверить вход гостя, сохранение инвентаря/монет/настроек и загрузку облачных данных. Закрыть игру во время открытия: списание и результат не повторяются.
5. Проверить rewarded до успешного просмотра, закрытие без награды, ошибку и отсутствие рекламы. Аимка всегда позволяет заработать без рекламы.
6. Проверить паузу и звук при рекламе, потере фокуса и SDK-паузе, включая их сочетания.
7. На настоящих Android/iOS проверить касания, звук, обе ориентации, поворот во время прокрутки и длинную сессию. Эмуляция браузера этого не заменяет.

## Оставшиеся условия отправки

Коммерческие права на 73 изображения CS не подтверждены. Источники записаны в `CS-ASSET-SOURCES-RU.md` и `artifacts/case-research/storm-image-provenance.json`. Не подтверждать наличие прав от лица владельца без применимого разрешения. Пользователь ранее просил сохранить оригинальную CS-графику; она не заменялась.

Владелец проверяет профиль, договор и платёжные данные в Консоли. До отправки нужны применимые права на графику, проверка настоящего SDK и финальная маркировка. Заполненный черновик и технически корректный архив не означают одобрение.

После устранения оставшихся вопросов отправить черновик на модерацию с включённой отсрочкой. Публикация — отдельное действие после одобрения. Не обещать дату и не считать тестовую ссылку публичным выпуском.
